# Relay Lab · 中转站模型实验室

Relay Lab 是一款本机运行的**中转站模型检测与对比工具**。你可以用同一组 prompt 测试不同 API 中转站上的 **Claude、GPT** 等模型，直观比较回答质量、调用成功率、首字时间、总耗时和 token 用量，并保存完整实验记录以便复查和重跑。支持 OpenAI Chat Completions 与 Anthropic Messages 协议，适合验证中转站连通性、模型表现和接口兼容性。

![Relay Lab 中转站模型检测工作台](artifacts/relay-lab-workbench.png)

## 启动

需要 Node.js 22.17+（或 Node.js 24）及 npm。

```sh
npm install
npm run build
npm start
```

打开 **http://127.0.0.1:3210**。服务只监听本机，不需要配置云服务。

开发模式使用 `npm run dev`，网页地址为 **http://127.0.0.1:5173**，后端端口仍是 3210。

可选环境变量：`RELAY_PORT`（后端端口）、`RELAY_WEB_PORT`（开发网页端口）、`RELAY_DATA_DIR`（数据目录，默认项目内 `data/`）。从项目根目录启动。

## 使用

1. 添加中转站：名称、协议、endpoint、API key、模型 ID（每行一个或逗号分隔）。支持基础地址和完整调用地址，保存前展示最终 URL。
2. 勾选需要比较的模型及测试任务。内置模型发布日期、糖果最少取出数、鹈鹕骑自行车 HTML/SVG 动画三个模板，使用用户提供的原文且不额外添加系统提示词，可预览并另存为自定义模板。修改自定义模板时版本号递增。
3. 设置重复次数、并发、超时和输出上限，检查总调用数后开始。默认每组合 3 次、并发 1、不限制超时、不指定输出 token 上限，流式调用，不自动重试。
4. 实时查看每个模型的完整回答，按任务、轮次并排比较；展开调用详情查看请求、结束原因和错误。
5. 历史可按名称、中转站、模型、状态与日期筛选。JSON 包含完整快照及逐次成果，CSV 为性能数据。JSON 可重新导入查看，并选择凭据按原配置重跑。

使用 OpenAI **Chat Completions** 和 Anthropic **Messages** 协议。OpenAI 协议可尝试获取模型列表；Anthropic 模型 ID 手动填写。不是 OpenAI Responses API。高级参数只加入请求体；不能覆盖模型、消息、stream、temperature、输出上限或认证。

超时和输出上限输入框留空表示不限制：本机不启动调用超时计时器，并关闭 HTTP 客户端内部的连接、响应头和响应体超时；不发送 `max_tokens`。上游仍可能施加自己的超时或模型输出上限。Anthropic Messages 原生协议要求 `max_tokens`，这类接口需要手动填写有限的输出上限，否则会如实记录接口错误，不会偷偷添加一个上限。

思考强度可在运行参数区选择：模型默认、none、minimal、low、medium、high、xhigh、max。默认不发送 effort 字段；OpenAI 兼容协议发送 `reasoning_effort`，Anthropic 发送 `output_config.effort`（none/minimal 只适用于 OpenAI）。模型支持哪些级别由上游决定，不支持时如实记录错误，不自动降级。不会额外修改 `thinking` 模式。选择 UI 强度后，高级 JSON 不能重复设置 effort；使用模型默认时仍可通过高级 JSON 配置。思考强度和实际请求均保存到历史快照，重跑沿用原设置。

默认不发送 temperature。部分推理模型不支持 `max_tokens` 或特定采样参数时，会如实记录接口错误，不进行隐藏降级。若模型需要不同协议，本版不能测试该模型。

OpenAI 流式接口要返回 token 用量，通常需在“额外请求参数”填写：

```json
{"stream_options":{"include_usage":true}}
```

这项默认不发送，兼容不支持该参数的中转站。若中转站不返回 usage，显示“用量不可用”，不会估算 token 数。

## 数据与指标

- 数据保存在 `data/relay.sqlite`。密钥以 AES-256-GCM 加密，解密用的 `data/master.key` 仅当前用户可读；目录权限 0700、文件权限 0600。
- 密钥不返回给网页，不写日志，不放进运行快照或导出。接口回显的已知密钥在持久化及展示前遮盖。备份时应整体保存 `data/`，包括 `master.key`，服务停止后复制；同机可读取这些文件的人仍可解密。
- 每次运行冻结 endpoint、协议、模型、prompt 正文及版本、参数和实际请求。重跑创建新实验，沿用这些字段；所选当前中转站只提供凭据，其新 endpoint 不替换历史地址。发送前页面会显示原地址。
- 关闭网页后测试继续执行。取消中止队列和正在执行的 HTTP 请求。服务重启后，未完成调用标记为“中断”，不会自动重试产生费用。
- 成功要求响应正常结束、可解析且有非空文本；达到输出上限仍是成功，但单独标记截断。空文本、异常 HTTP、超时、协议错误、流中断均失败；已有的部分输出保留。
- 成功率为成功 /（成功 + 失败），取消、中断、排队项不进入分母。中位数和 P95 只计算成功调用；P95 使用最近秩法，少量样本时往往等于最大值。
- 首字时间为后端开始调用至首个非空回答文本到达，不包括角色事件和思考内容。非流式无法测首字时间。总耗时包含网络等待和响应接收。
- 输出吞吐为接口报告的输出 tokens / 总耗时，不代表模型纯生成速度。未知用量不计算吞吐。
- “可复现”指能重用相同请求配置，不保证模型输出逐字一致，也不能证明中转站的底层实际模型身份。质量由阅读成果判断，本版没有自动评分。

导入文件限制 32 MB，版本必须是 Relay Lab v1，调用数量及请求必须匹配快照；单次实验最多 2000 个调用，最多同时运行 3 个实验。导出不包含 API key，导入后需要重新绑定本机凭据才能重跑。

## 验证

```sh
npm test
npm run check
npm run build
npm run test:ui
npm audit
```

浏览器测试默认使用已安装的 Google Chrome，自动启动独立的本机服务及临时数据库，结束后清理。可设置 `PLAYWRIGHT_CHANNEL=chromium` 改用 Playwright Chromium，并先执行 `npx playwright install chromium`。

测试使用本机模拟的上游 HTTP/SSE 服务，不会调用真实收费模型。覆盖两种协议的分片、错误、空内容、用量、限流、超时、取消、密钥轮换、重启恢复、冻结请求、导入导出、浏览器对比与历史保存。真实中转站需由用户填写凭据后验证。

## 项目结构

- `server/`：本机 API、协议适配、SQLite、凭据、任务队列和导入导出。
- `shared/`：请求、快照与结果类型及默认设置。
- `src/`：React 网页、配置编辑、成果对比和历史记录。
- `tests/`：HTTP fixture、集成与浏览器测试。

前端字体随项目打包；界面不依赖在线字体。模型输出可切换 Markdown、原文或 HTML/SVG 预览。预览支持完整文档、HTML/SVG 代码块、多代码块选择、内联脚本动画、放大和重播；生成结束后才运行预览。使用无同源权限的 sandbox iframe 和 CSP 隔离，外部脚本、图片、字体、网络请求等资源不加载，因此依赖 CDN 的成果可能无法完整显示。预览从保存的原文提取，不修改历史或导出内容。此工具面向本机单用户使用，不用于公开托管。
