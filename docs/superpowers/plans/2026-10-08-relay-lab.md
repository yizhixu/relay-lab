# Relay Lab Implementation Plan

Goal: 完成已确认的本机中转站模型测试工作台。
Architecture: React界面使用同源REST及SSE；Fastify管理SQLite、加密凭据与后台队列；协议适配器只发出被冻结的请求。
Tech Stack: TypeScript, React, Fastify, better-sqlite3, Vitest, Playwright.
Spec: ../specs/2026-10-08-relay-lab-design.md

## Constraints and review focus
仅本机监听，密钥不导出；默认3轮/1并发/120秒/2048tokens；无自动重试。
重点验证：完整URL拼接、流分片及终止标记、无usage、取消与重启、修改配置后的快照、导入输入校验与密钥泄露、SSE断线恢复。

## Tasks
- [x] 1. Shared types, presets, request builder and metrics. Tests assert URL joining, protocol bodies, reserved parameters, percentile and success denominator. Run failing tests then implement.
- [x] 2. SQLite store and encrypted keys. Tests assert CRUD, snapshots, secret exclusion and restart interruption. Run failing tests then implement.
- [x] 3. Streaming adapters and runner. Local HTTP fixture tests assert both protocols, failures, partial output, cancellation, concurrency and no retries. Run failing tests then implement.
- [x] 4. Fastify REST/SSE, export/import/replay. Injection tests assert validation, snapshot replay, key rebinding and version checks. Run failing tests then implement.
- [x] 5. React working surface, providers, templates, runs, compare, history. Playwright verifies two providers, run, export, history, replay and responsive UI.
- [x] 6. Fresh typecheck/build/test, review, README and running local handoff.
