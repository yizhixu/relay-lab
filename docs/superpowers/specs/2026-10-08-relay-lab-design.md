# Relay Lab — 已确认设计
本机运行的中文网页测试工具。React / TypeScript / Vite + Fastify + SQLite。
支持 OpenAI Chat Completions 与 Anthropic Messages 文本模型，多个站点、模型、prompt 的矩阵测试。
六类预制任务，可编辑保存。默认重复3次，并发1，120秒超时，2048输出tokens，流式，不自动重试或降级。temperature 默认不发送。
API key 后端加密持久化，本机密钥文件0600；不导出或写日志。仅监听127.0.0.1。
保存完整回答、失败、首字时间、总耗时、用量及冻结请求。质量由用户看成果判断，无自动评分。
运行后端队列，页面关闭继续运行；取消中止请求和队列；服务重启未完成项标记中断。
历史查看、JSON/CSV导出、JSON导入、凭据重新绑定、按冻结快照重跑。
成功是正常完成、可解析、有非空文本；截断成功单列，流中断算失败并保留部分输出。
重跑相同参数不承诺输出相同。仅本机单用户，无公开部署、自动代码执行、多模态或裁判模型。
